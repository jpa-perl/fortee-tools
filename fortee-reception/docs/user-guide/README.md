# 受付アプリの使い方

受付スタッフ向けの説明です。受付アプリは、来場者のチケットの QR コードを自分のスマートフォンで読み取り、受付（チェックイン）を記録するアプリです。

受付は、次の 3 つの操作の繰り返しです。

1. 「QR コード読み取り」を押して、来場者の QR コードにカメラを向ける
2. 画面に出た名前を確かめて「続ける」を押す
3. 緑の画面が出たら、「次へ」を押す

## 読む順番

はじめての人は、次の表の 1 と 2 を順に読めば受付ができます。

| ページ | 内容 | 読むとき |
| --- | --- | --- |
| [1. 準備する](setup.md) | アプリをスマートフォンに入れて、ログインする | はじめに |
| [2. 受付をする](checkin.md) | QR コードを読み取って受け付ける | はじめに |
| [練習する](practice.md) | 記録を残さずに操作を試す | 時間があるとき |

残りのページは、その場面になったときに開いてください。

| ページ | 開く場面 |
| --- | --- |
| [QR コードを出せない人を受け付ける](search.md) | 来場者が QR コードを見せられない |
| [黄色や赤の画面が出たとき](results.md) | 読み取ったら緑以外の画面が出た |
| [受付を取り消す](undo.md) | まちがえて受け付けた |
| [困ったとき](troubleshooting.md) | カメラが動かない、ログインできない、見慣れない表示が出た |

## このガイドについて

- アプリの URL、受付の名前と時間、画面に出る参加者の情報の項目は、カンファレンスごとの設定で決まります
- 画面の画像は、YAPC::Tokyo 2026 の設定で撮った例です。写っている名前とチケットは架空のものです
